## 2. Technology Stack & Design System

- **Framework:** React 19 + Vite 8
- **Routing:** React Router v7
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Brand Palette:**

  - Royal Blue: `#246BCE`
  - Restrained Teal: `#17A6A1`
  - Neutral Surface: `#F6F8FB`

## 3. Running & Building Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build

# Preview production build
npm run preview
```

## 4. Owner Verification Checklist Before Public Launch

1. **Company Legal Name & Registration:** Confirm official registered entity name in `src/data/companyData.js`.
2. **Founding Year Claim (2012):** Verify founding year against incorporation records.
3. **Contact Information:** Update office address, official PBX phone numbers, and authorized emails in `src/data/companyData.js`.
4. **Product Launch Statuses:** Confirm maturity levels (`Live`, `Pilot`, `Early Access`, `In Development`) in `src/data/platformsData.js`.
